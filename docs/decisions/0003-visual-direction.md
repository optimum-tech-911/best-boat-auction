# Visual direction

2026-10-05. Accepted direction for the new homepage hero and reusable design tokens.

Marine navy #0B1F33, warm ivory #F6F4EF, restrained deep teal #2E7477, warm stone borders #D8D2C6. Burnt orange #C86B32 is restricted to the live dot and large urgency numerals; normal text stays ivory on navy.

Instrument Serif is the display font and Inter is the interface font. Both use local, self-hosted WOFF2 files via next/font. Prices and countdowns use tabular numerals.

The hero uses full-width photography, editorial typography, square or subtly rounded buttons, restrained entrance animation and a flat auction rail. No floating cards, decorative continuous animation, scroll hijacking or parallax.

The reference header and other sections retain their original layout during this task. The new tokens will be applied to each section as its design is approved.
